HOW TO BUILD (3 METHODS)
════════════════════════════════════════════════════════════════════════════════

METHOD 1: AUTO BUILD ON PUSH (Every commit)
────────────────────────────────────────────
1. Edit file in GitHub web
2. Click "Commit changes"
3. Go to Actions tab
4. Watch build run
5. Download artifact when done

Time: 5-10 minutes
Automation: FULL


METHOD 2: MANUAL BUILD (On demand)
──────────────────────────────────
1. Go to Actions tab
2. Click "Build CoreFlow Module"
3. Click "Run workflow" button
4. Confirm "Run workflow"
5. Wait for completion
6. Download artifact

Time: 5-10 minutes
Automation: PARTIAL


METHOD 3: RELEASE (Publish version)
────────────────────────────────────
1. Go to Releases tab
2. Click "Create a new release"
3. Tag: v3.0
4. Title: CoreFlow v3.0
5. Click "Publish release"
6. Workflow runs automatically
7. ZIP attached to release
8. Download from release page

Time: 5-10 minutes
Automation: FULL

════════════════════════════════════════════════════════════════════════════════
DOWNLOAD ARTIFACT
════════════════════════════════════════════════════════════════════════════════

FROM BUILD WORKFLOW:
  1. Repository → Actions
  2. Click latest "Build CoreFlow Module"
  3. Scroll down: Artifacts
  4. Click "CoreFlow-Build"
  5. Download .zip
  6. Extract CoreFlow_v3.0.zip

FROM RELEASE:
  1. Repository → Releases
  2. Click latest release (v3.0)
  3. Under Assets: CoreFlow_v3.0.zip
  4. Click to download
  5. Done!

════════════════════════════════════════════════════════════════════════════════
INSTALL ON DEVICE
════════════════════════════════════════════════════════════════════════════════

1. Download CoreFlow_v3.0.zip
   ↓
2. Push to device
   adb push CoreFlow_v3.0.zip /sdcard/
   ↓
3. Flash in Magisk Manager
   Modules → + → CoreFlow_v3.0.zip
   ↓
4. Reboot device
   ↓
5. Verify
   adb shell pidof coreflow_daemon  → Should show PID

════════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Workflow not running"
SOLUTION: Check if .github/workflows/*.yml files exist and committed

PROBLEM: "Build failed"
SOLUTION: Click workflow → See error log → Fix code → Push again

PROBLEM: "Can't download artifact"
SOLUTION: Wait for green ✓ check → Go to Artifacts section

PROBLEM: "Release not showing"
SOLUTION: Go to Releases tab (not Actions) → Should appear after workflow

PROBLEM: "ZIP is empty"
SOLUTION: Workflow failed → Check logs for error
