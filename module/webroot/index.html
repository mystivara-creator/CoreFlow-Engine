ENGINE PHILOSOPHY

Evidence before action

CoreFlow keeps discovery, readability, write capability, authorization, and verified outcomes distinct. Missing telemetry remains unknown instead of being fabricated.

Adaptive is an operating policy, not a blanket permission; actual changes remain subject to the engine's configured authorization and validation path.

SECURITY & GOVERNANCE

Auditable control path

Resource changes are expected to pass capability checks, policy evaluation, journaling, bounded writes, read-back verification, and recovery handling.
