GITHUB ACTIONS WORKFLOW
════════════════════════════════════════════════════════════════════════════════

NAME: Build CoreFlow Module
FILE: .github/workflows/build.yml

TRIGGERS:
  ✓ Every push to main/develop branches
  ✓ Every pull request
  ✓ Manual trigger from Actions tab

STEPS:
  1. Checkout repository code
  2. Setup Android NDK (r25b)
  3. Compile C++ daemon → ARM64 binary
  4. Strip binary (reduce size)
  5. Create Magisk module structure
  6. Package flashable ZIP
  7. Generate checksums (SHA256, MD5)
  8. Upload as artifacts

OUTPUT:
  • CoreFlow_v3.0.zip (650 KB)
  • CoreFlow_v3.0.zip.sha256
  • CoreFlow_v3.0.zip.md5
  • BUILD_INFO.txt
  • Available in Artifacts section

TIME: 5-10 minutes

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

PROBLEM: Workflows not showing in Actions tab
SOLUTION: 
  1. Check .github/workflows/ path is correct
  2. Verify files named build.yml and release.yml
  3. Check files are committed (not just staged)
  4. Refresh page (F5)

PROBLEM: Build fails
SOLUTION:
  1. Click workflow
  2. See red ✗ status
  3. Check error in logs
  4. Common: NDK version mismatch, file path wrong
  5. Fix code
  6. Push again - auto-rebuild

PROBLEM: Can't download artifact
SOLUTION:
  1. Wait for green ✓ complete
  2. Go to Artifacts section
  3. Download CoreFlow-Build
  4. Extract .zip

PROBLEM: Release doesn't auto-attach ZIP
SOLUTION:
  1. Workflow must complete (green ✓)
  2. Takes 5-10 minutes
  3. Artifacts auto-attach
  4. Refresh release page
