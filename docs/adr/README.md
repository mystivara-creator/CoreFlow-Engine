# Architecture Decision Records

Use this directory for short, immutable records of important engineering decisions.

## File naming

```text
NNNN-short-decision-title.md
```

Example: `0001-use-cpp20-for-core-runtime.md`.

## Template

```markdown
# NNNN. Decision title

## Status

Accepted | Proposed | Superseded by NNNN

## Context

Why this decision was needed.

## Decision

What was decided.

## Consequences

Benefits, trade-offs, and follow-up work.
```
