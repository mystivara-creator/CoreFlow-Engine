# Build Status — v1.3.0

This is the **v1.3.0 source package** of CoreFlow Autonomous Engine.

## Package contract

This archive is a **source package**, not a directly installable production module. It intentionally contains no pre-built ARM64 `coreflowd` and no bundled `libonnxruntime.so`. Production binaries are generated by CI or by the Android build helper with an externally supplied ONNX Runtime package.

## Included

- Complete C++17 source (`src/`, `include/`)
- Magisk module scaffolding and runtime configuration (`module/`)
- Deterministic host tests
- Android ARM64 production CI workflow
- Pinned thermal ONNX model
- Source-release verification tooling

## Excluded from source package

- `build/` and other generated build directories
- Pre-built ARM64 ELF (`coreflowd`)
- Pre-built `libonnxruntime.so`
- Extracted ONNX Runtime SDK/cache
- CI artifacts

## Canonical toolchain

| Component | Version |
|---|---|
| CoreFlow | `1.3.0` |
| Android ABI | `arm64-v8a` |
| Android API | `35` |
| Android NDK | `27.3.13750724` |
| ONNX Runtime Android | `1.24.3` |

The local Android helper and CI use the same Android API/NDK contract. ONNX Runtime is supplied externally and must match the expected package layout.

## Validation

The source package is expected to pass:

```sh
tools/verify_source_release.sh
cmake -S . -B build/host -G Ninja -DCORE_FLOW_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build/host
ctest --test-dir build/host --output-on-failure --no-tests=error
```

## Safety status

- Mutation default: `disabled`
- Mutation journal: enabled for mutation paths
- Write/read-back verification: implemented
- Restore/rollback path: implemented
- Fail-closed handling: implemented
- Device-specific policy validation: required before enabling adaptive mutation

## Release interpretation

`v1.3.0` is a source-package release with release-engineering hardening and version/toolchain alignment. It does not claim that the generated Android binary has been validated on every device or kernel configuration.
