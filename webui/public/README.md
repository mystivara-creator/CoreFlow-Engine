# CFAE System Framework v3.0.R WebUI Public Assets

Vite copies these static assets into `module/webroot` during build so both standard web preview deployments (`dist/`) and KernelSU / APatch / Magisk offline packaging remain 100% identical and synchronized.

Native mode is capability-driven: the Material Design 3 dashboard reads `coreflowd --status`, the discovered top-app UClamp pair, the multi-sensor thermal matrix, durable write-ahead journal state, and daemon audit logs. Browser mode is an explicitly labelled simulation of the 5-layer Coordinated Mutation Safety architecture.

Unverified metrics such as synthetic FPS, frame-time, or jank are never claimed without a validated platform source.
